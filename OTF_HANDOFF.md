# OTF handoff

## Direction

OTF means Only the Family. Build an app for families to connect, socialize, stay in touch, and record their family tree. Begin with the founder's family and eventually support separate family spaces for others.

## Current milestone

Repository and product foundation only. No application code, runtime, deployment, authentication, or database is present yet. The user has been asked to select the initial platform.

## Next work

1. Incorporate the user's initial platform choice.
2. Scaffold the client and document local run commands.
3. Build a fictional-data prototype covering the family feed and tree.
4. Validate the prototype before implementing the private family pilot backend.

Public source code is authorized. Real family data must not be included in the repository or a public demo.

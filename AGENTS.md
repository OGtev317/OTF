# OTF contributor guidance

- OTF means Only the Family. Read README.md, docs/PRODUCT.md, and OTF_HANDOFF.md before continuing.
- Keep this project independent of other local projects.
- The source repository is public; family information is private by default.
- Use fictional demo data only. Do not commit personal family records, private photos, credentials, database dumps, or account material.
- Distinguish planned privacy controls from implemented and verified behavior.
- Keep family-tree people separate from login accounts; support relatives without accounts and varied family structures.
- Enforce family authorization at the server boundary when a backend is introduced.
- Record the current implementation status and verification in OTF_HANDOFF.md.
